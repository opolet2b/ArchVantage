* Whenever you need to use a LLM in the canvas, you must use the configuration that is selected in the drop downs at the top panel of the canvas. there is one drop down for LLM and one drop down for VML. These drop downs contain configurations. These configuration correspond to standard configurations defined in the settings. In the configuration is the exact reference of the LLM or VLM to be used nd how to access it (Ollama or LLM gateway configuration etc.)
