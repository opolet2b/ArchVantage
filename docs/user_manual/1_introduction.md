# Volume 1: Introduction to SemanticCanvas

## 1. Overview
SemanticCanvas is a spatial computing environment designed to transform how you interact with information and AI. By moving beyond the linear constraints of traditional chat interfaces, SemanticCanvas allows you to organize data, agents, and workflows in a persistent, infinite spatial field.

## 2. Core Philosophy
### 2.1 Spatial Reasoning
Humans naturally think in space. SemanticCanvas leverages this by allowing you to group related concepts together, visualize relationships through links, and build hierarchical structures using Domains.

### 2.2 Semantic Zoom
Information density adapts to your perspective. 
- **Zoomed Out**: See high-level labels and summaries of entire domains.
- **Zoomed In**: Reveal detailed text, media, metadata, and interactive controls.

## 3. Getting Started
1.  **Create a Canvas**: Start with a blank slate or a template.
2.  **Add Things**: Drag and drop files, paste URLs, or create text nodes.
3.  **Organize**: Group nodes into Domains to create context.
4.  **Automate**: Drop nodes onto specialized Agent Zones to trigger analysis.

## 4. Key Terminology
- **Thing**: Any discrete piece of data (Text, File, Agent).
- **Domain**: A container that provides context and rules for its contents.
- **Link**: A semantic relationship between two Things.
- **Scenario**: A global configuration that defines the look and feel of your workspace.
