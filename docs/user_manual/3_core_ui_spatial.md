# Volume 3: Core UI & Spatial Reasoning

## 1. The Canvas Experience
The Canvas is a limitless workspace where you visualize your thoughts.
- **Infinite Space**: Use your mouse or trackpad to pan and navigate.
- **Node Interaction**: Click to select, drag to reposition, and use handles to resize.
- **Multi-Select**: Hold Shift and drag to select multiple nodes for batch operations.

## 2. Semantic Zoom (LOD)
SemanticCanvas uses "Level of Detail" (LOD) to manage information density.
- **Far Zoom**: Groups of nodes condense into cluster summaries or domain titles.
- **Medium Zoom**: Nodes show labels and concise one-liner summaries.
- **Close Zoom**: Full markdown content, interactive buttons, and metadata panels appear.

## 3. Domains & Hierarchies
Domains are more than just boxes; they are contextual containers.
- **Nesting**: Place a node inside a Domain to associate it with that context.
- **Metadata Inheritance**: Files moved into a "Legal" domain can automatically inherit legal-specific metadata tags.
- **Interactive Boundaries**: Domains can be resized and their background colors/icons customized via the Domain Selector.

## 4. Navigation & Shortcuts
- **Space + Drag**: Pan the canvas.
- **Mouse Wheel**: Zoom in and out.
- **Ctrl + F**: Semantic search within the current canvas.
- **Right-Click**: Access context-sensitive menus for Nodes, Domains, or the Background.
