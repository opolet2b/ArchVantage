# Volume 4: Knowledge Management

## 1. Master the "Thing"
A "Thing" is the fundamental unit of information in SemanticCanvas.
- **Metadata Panel**: Inspect any node to see its type, source, timestamps, and AI-generated summaries.
- **Conversion**: Transform a URL into a summarized Markdown node or a set of extracted entities.
- **Linking**: Drag a connection from one node to another to define a relationship (e.g., "Supports," "Contradicts").

## 2. Knowledge Base Ingestion
Bring external data into your spatial environment.
- **File Uploads**: Supports PDF, Word, Excel, PowerPoint, and Images.
- **VLM Enrichment**: When uploading complex PDFs (with charts or diagrams), select "Vision Enrichment" to have the AI describe visual elements in text.
- **Folder Sync**: Coming soon - monitor local directories for automatic ingestion.

## 3. RAG (Retrieval-Augmented Generation)
Your personal library, indexed and ready for questioning.
- **Semantic Search**: Search based on meaning, not just keywords.
- **Context Selection**: Pin specific nodes or entire domains as "Ground Truth" for your AI chat sessions.
- **Source Transparency**: Every AI response includes clickable citations that highlight the exact source document on your canvas.

## 4. Data Hygiene
- **Vector Status**: Icons indicate if a node is indexed (Green), processing (Spinning), or failed (Red).
- **Cleanup tools**: Use the Admin panel to re-index or clear outdated vector storage.
