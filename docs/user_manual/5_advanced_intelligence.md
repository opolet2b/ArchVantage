# Volume 5: Advanced Intelligence

## 1. Smart Analysis
Turn raw data into structured frameworks with a single click.
- **Frameworks**: Right-click a node or group to run specialized analyses:
    - **PESTEL**: Political, Economic, Social, Technological, Environmental, Legal.
    - **SWOT**: Strengths, Weaknesses, Opportunities, Threats.
    - **Gap Analysis**: Compare "As-Is" vs "To-Be" states.
- **Contextual Awareness**: The AI takes into account the "Domain" the node is in to tailor its analysis.

## 2. Smart Templates
Generate high-fidelity, production-ready documents.
- **Iterative Drafting**: Templates don't just "write" once; they draft, audit, and refine.
- **The Auditor**: A background agent checks the draft for consistency, accuracy, and tone.
- **Quality Targets**: Set a "Minimum Quality Score" (e.g., 85%). The system will loop and refine until the goal is met or the max iterations are reached.

## 3. Using Templates
1.  **Select Context**: Select the nodes you want to base the document on.
2.  **Choose Template**: Pick from "Executive Summary," "Technical Spec," "Legal Brief," etc.
3.  **Execute**: Watch the progress bar as the AI moves through the Draft -> Audit -> Refine loop.
4.  **Review**: Open the final generated "Thing" to see the polished output.
