# SemanticCanvas User Manual Suite

Welcome to the comprehensive user manual for SemanticCanvas. This suite is divided into specialized volumes to help you master every aspect of the platform.

## Manual Volumes

1.  **[Introduction](1_introduction.md)**: Explore the mission, core concepts, and how to get started.
2.  **[System Architecture](2_system_architecture.md)**: A high-level technical overview of the platform's stack and data flow.
3.  **[Core UI & Spatial Reasoning](3_core_ui_spatial.md)**: Master the canvas, semantic zooming, and hierarchical domains.
4.  **[Knowledge Management](4_knowledge_management.md)**: Learn about Things (Nodes), RAG ingestion, and the Knowledge Base.
5.  **[Advanced Intelligence](5_advanced_intelligence.md)**: Deep dive into Smart Analysis and iterative Smart Templates.
6.  **[Agents and Automation](6_agents_and_automation.md)**: Create and orchestrate agent blueprints and workflows.
7.  **[Ontology & Semantic Graph](7_ontology_graph.md)**: Build taxonomies and navigate the knowledge graph.
8.  **[Tools & MCP](8_tools_and_mcp.md)**: Extend capabilities with external tools and the Model Context Protocol.
9.  **[Admin, Security & Maintenance](9_admin_and_security.md)**: Manage permissions, data models, and system health.
