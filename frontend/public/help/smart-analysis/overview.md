# Smart Analysis Overview

The **Smart Document Analysis Framework** is a powerful tool designed to automate the processing of complex documents.

## Key Features

*   **Template-Based Workflow**: Create reusable analysis pipelines.
*   **Intelligent Extraction**: Use AI to extract specific data from PDFs and images.
*   **Reasoning Agents**: Apply specialized personas (e.g., Auditor, Legal Expert) to analyze content.
*   **Structured Output**: Generate reports in Markdown, JSON, or CSV formats.

## Getting Started

1.  Go to the **Template Library** to view available templates.
2.  Open the **Workbench** to create or edit a template.
3.  Drag and drop modules to build your analysis flow.
