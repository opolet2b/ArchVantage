# Step Configuration

Every step in your pipeline can be customized using the Configuration Panel on the right.

## How to Configure
1.  **Select a Step**: Click on any node in the canvas.
2.  **Edit Parameters**: The panel will show options specific to that module type.
3.  **Apply Changes**: Click the "APPLY CHANGES" button at the bottom to save your settings.

## Common Settings
*   **Step Name**: Rename steps for clarity (e.g., "Extract Financials").
*   **Description**: Add notes about what this step does.

## Module-Specific Settings
*   **Extractors**: Choose the source section.
*   **Agents**: Select the Persona and Analysis Framework.
*   **Visualizers**: Choose the chart type and title.
