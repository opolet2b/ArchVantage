# System Prompt

The instructions that define how the tool's internal agent should behave.

When you use the **"Generate Schema"** button, the system analyzes this prompt to automatically create the input parameters (Input Schema) required for your tool.

### Example
*"You are a weather assistant. You require a 'city' and optionally a 'country' to provide weather forecasts."*

This would generate a schema requiring `city` and listing `country` as optional.
