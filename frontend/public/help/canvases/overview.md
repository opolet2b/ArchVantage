# Canvases

The **Canvas** is your infinite, visual workspace for thinking, planning, and building with AI.

## Key Concepts

### 1. Infinite Workspace
Click and drag to pan around. Scroll to zoom in and out. There are no boundaries to your thinking.

### 2. Nodes
Everything on the canvas is a **Node**. 
- **Text Notes**: Simple markdown notes.
- **Files**: Uploaded PDFs, Images, or Documents.
- **Cards**: Rich interactive elements (like YouTube videos or Web pages).
- **AI Agents**: Smart nodes that can process information.

### 3. Connections
Draw lines between nodes to establish **Context**. 
- Connecting a Document to an AI Agent allows the Agent to "read" that document.
- Connecting two Agents allows them to pass messages.

## Actions

### Creating Nodes
- **Double Click** anywhere to create a quick text note.
- **Drag & Drop** files from your computer directly onto the canvas.
- Use the **Toolbar** (bottom center) to add specific tools or agents.

### Organizing
- **Select**: Click to select a node. Hold `Shift` to select multiple.
- **Group**: Select multiple nodes and press `Ctrl+G` (or use the context menu) to group them.
- **Link**: Hover over the edge of a node to find the connection dot, then drag to another node.

## Smart Features
- **Smart Analysis**: Right-click a selection of nodes and choose a "Template" (like SWOT Analysis) to instantly generate a report.
- **Chat**: Selecting nodes and opening the Chat panel (right) lets you ask questions specifically about those selected items.
