# Domain Metadata

Metadata in domains is a powerful way to add structure and intelligence to your canvas. It serves several key purposes:

### 1. Governance and Compliance
Metadata can be used to enforce standards. For example, you can define a "Status" field to ensure all Things in a domain are compliant with your workflow. Non-compliant items can be visually highlighted based on these rules.

### 2. Domain-Specific Agent Context
Agents used within a domain can use metadata to tailor their processing. For example, if a domain is focused on "Security", agents dropping into that domain will automatically apply a "Security First" lens to their analysis.

### 3. Automatic Labeling
Things dropped into a domain can be automatically labeled based on the domain's metadata. This ensures that every item added to the workspace is immediately enriched with relevant context for future analysis.

### 4. Intelligent Categorization
Metadata enables automatic categorization by matching the attributes of Things with those of Domains. This allows for sophisticated data routing and organization based on semantic properties.
