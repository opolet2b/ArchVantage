# Retrieval Mode

Strategies for finding relevant content.

### Dense (Embedding) Only
- **Pros**: Catches semantic meaning ("Dog" matches "Puppy"). Best for general conceptual queries.
- **Cons**: Can struggle with exact keywords (e.g., Part Number "XJ-900").

### Hybrid (Sparse + Dense) *Coming Soon*
- **Pros**: Best of both worlds. Matches concepts *and* specific keywords.
- **Cons**: Slower indexing and larger storage requirements.
