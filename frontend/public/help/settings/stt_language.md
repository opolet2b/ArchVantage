# STT Language Code

Select the language for speech recognition.

- **Whisper (Remote/Local)**: Use 2-letter ISO codes (e.g., `en`, `fr`, `de`). "Auto-detect" will let the model guess the language.
- **Browser Native**: Use BCP 47 tags (e.g., `en-US`, `fr-FR`).

Providing a specific language code significantly improves transcription accuracy and reduces latency.
