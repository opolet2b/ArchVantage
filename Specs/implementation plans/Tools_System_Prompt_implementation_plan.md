# Implementation Plan - System Prompt Generation

## Goal
Automatically generate a System Prompt for a tool based on its description and selected MCP functions, using an LLM.

## User Review Required
None.

## Proposed Changes

### Backend

#### [MODIFY] [app/schemas/tools.py](file:///c:/Users/opole/Downloads/ChatBotn/backend/app/schemas/tools.py)
- Add `SystemPromptGenerationRequest` schema with fields:
    - `description`: str
    - `functions`: List[str] (names of selected functions)
    - `server_info`: Optional[str] (context about the server)

#### [MODIFY] [app/services/tools.py](file:///c:/Users/opole/Downloads/ChatBotn/backend/app/services/tools.py)
- Add `generate_system_prompt` method.
- Construct a prompt for the LLM including the tool description and function list.
- Call `LLMService.chat` to get the generated prompt.

#### [MODIFY] [app/routers/tools.py](file:///c:/Users/opole/Downloads/ChatBotn/backend/app/routers/tools.py)
- Add `POST /generate-prompt` endpoint using `SystemPromptGenerationRequest`.

### Frontend

#### [MODIFY] [tool-editor.tsx](file:///c:/Users/opole/Downloads/ChatBotn/frontend/src/components/tools/tool-editor.tsx)
- Add "Generate" button in the System Prompt section.
- Implement `handleGeneratePrompt` function to call the backend API.
- Update the system prompt textarea with the response.

## Verification Plan

### Manual Verification
1.  Open the Tools page and create/edit a tool.
2.  Enter a description (e.g., "A tool to calculate VAT").
3.  Select some MCP functions (mocked or real).
4.  Open the "Configure Prompt" section.
5.  Click "Generate".
6.  Verify that the system prompt textarea is populated with a relevant prompt generated by the LLM.
