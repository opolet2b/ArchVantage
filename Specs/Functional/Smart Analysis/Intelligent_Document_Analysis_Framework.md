## **2\. Results Catalog (UI Rendering)**

This list defines the different ways how the analysis can be rendered.

### **A. Short Answers & Summaries**

* **Single Sentence**: Direct and ultra-concise response.  
* **Executive Summary**: 3 impact points and 1 strategic recommendation.  
* **Bullet Points**: Ordered list of essential information.

### **B. Business & Strategic Models**

* **SWOT Matrix**: Strengths, Weaknesses, Opportunities, Threats.  
* **PESTEL Analysis**: Political, Economic, Social, Tech, Environmental, Legal.  
* **Porter’s 5 Forces**: Analysis of competitive pressure.  
* **BCG Matrix**: Stars, Cash Cows, Question Marks, Dogs.  
* **Value Chain**: Analysis of value creation stages.

### **C. Technical Diagrams & Modeling (Mermaid/SVG)**

* **UML Diagrams**: Sequence, Class, Activity, State Machine, Component, Deployment.  
* **Enterprise Arch.**: Archimate (Business, Application, Technology, Motivation).  
* **Process Mapping**: BPMN, Flowchart, CI/CD Pipeline.  
* **Data Modeling**: ER Diagram, Snowflake/Star Schema, Ontology Model.  
* **C4 Model**: Software architecture visualization.

### **D. Security & Risk Frameworks**

* **MITRE ATT\&CK**: Matrix of adversarial tactics and techniques.  
* **STRIDE / DREAD**: Threat modeling and risk assessment.  
* **CVSS Score**: Vulnerability severity calculation.  
* **NIST Framework**: Alignment with cybersecurity pillars.

### **E. Project Management & Planning**

* **Gantt / PERT**: Project schedule and time dependencies.  
* **Kanban Board**: Task status and workflow.  
* **Roadmap**: Macro-temporal vision of deliverables.

## **3\. Advanced Parameters for Smart Templates**

This table defines the parameters that can influence how the analysis is done.

| Parameter | Description | Typical Options |
| :---- | :---- | :---- |
| **Thesaurus** | Priority industry lexicon. | Pharma (HL7), Aero (ASD), Finance, Legal |
| **Logic Depth** | AI reasoning level. | Chain of Thought, Fast Response, Deep Audit |
| **Evidence Level** | Depth of provided proof. | Full Snippet, Page Reference, None |
| **Visual Style** | Aesthetic of diagrams. | Minimalist, Detailed, Hand-drawn |
| **Language** | Result target language. | Source, FR, EN, ES, DE |
